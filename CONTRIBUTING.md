# Contributing to the Ember Corps field archive

The website is the authoritative player reference. Edit the Markdown sources in this repository and keep shared rules consistent across all references.

- Report a typo, broken anchor or display issue with a GitHub issue.
- Obtain staff approval for mechanics changes before publication.
- Update affected volumes and references together after approval, and describe mechanical changes in the commit or pull request. Approved changes are announced in [Discord](https://discord.com/channels/1538632131402793080/1542862638663344289).
- Verify that section search anchors still match the search index after editing headings.
- Do not paste private GM or staff-only materials into this public repository.

The site uses GitHub Pages / Jekyll, Markdown source pages under `rules/`, and plain CSS and JavaScript in `assets/`.
